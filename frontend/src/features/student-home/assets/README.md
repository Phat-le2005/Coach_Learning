# Homepage assets

The Be Vietnam Pro and Patrick Hand fonts are self-hosted WOFF2 files derived from
the Google Fonts distributions. Their SIL Open Font License notices are included.
Patrick Hand renders a clearly labeled feature illustration; it is neither a
student capture nor a recognition result.

The constant SVG bodies in `../components/home-icons.json` come from the official
Phosphor Icons duotone set (MIT). No user input reaches the SVG markup. Copyright
and permission notice: `PHOSPHOR-LICENSE.txt`. Sources and SHA-256 hashes are in
`SOURCES.json`. There are no runtime CDN calls, private ink captures or datasets.

Theme colors live in `HomeRefresh.module.css`, scoped to the student homepage.
The existing knowledge visualization, action resolver, study-plan endpoints,
account menu and nature effects remain the runtime sources of truth.
