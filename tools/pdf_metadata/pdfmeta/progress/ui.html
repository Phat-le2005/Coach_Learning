Một PDF. Một luồng xử lý.

Kéo PDF thả vào tools\pdf_metadata\process_pdf.cmd trong thư mục Coach_Learning. Trang theo dõi sẽ mở khi lượt chạy bắt đầu.

Hoặc mở PowerShell tại thư mục repository và chạy:

.\tools\pdf_metadata\process_pdf.ps1 "E:\tai-lieu.pdf" -Open

Khi bị ngắt, chạy lại cùng file để tiếp tục từ checkpoint. File kết quả vẫn giữ những phần chưa đọc chắc để xử lý tiếp.
